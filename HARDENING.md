# Hardening plan

The open list of product-hardening work, rewritten on 2026-10-29 from a deep review of the whole product (seven
read-only passes: run-time, control plane, security, web app, Copilot and evaluation, framework adapters and exports,
feature completeness and docs) and a check of the market and the standards the product speaks. Everything finished
before this date was removed from here; its history is in `CHANGELOG.md` (the *Unreleased* sections and v0.28–v0.32)
and `decisions.md`.

**How to use this file.** One PR per item; every fix lands with a test that fails without it. In the same PR, delete
the item here (or move what is left of it to the right section) and add anything new you find. Items carry an id
(`R-1`, `S-2`, …) so a PR title can name them. *Confirmed* means the reviewer reproduced it with a script or test in
this repository; *plausible* means it follows from reading the code and still needs a reproduction, which is the
first step of the fix.

Severity: **critical** = loses data, stops the service or crosses a tenant boundary; **high** = a user hits it in
normal use and there is no workaround short of a reload or restart; **medium** = wrong result or a dead end with a
workaround; **low** = edge case or hygiene.
