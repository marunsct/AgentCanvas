# Building for Google ADK

The workflow becomes an ADK 2 graph workflow: a function node per block, joined with ADK edges, route dicts and
JoinNodes; AI blocks are ADK Agents on LiteLLM models. Approvals, questions and tool-call approvals are native there.

Before proposing the move, call `export_plan` for this framework and tell the person what it lists. Say what the
framework will not do; promise nothing the facts below do not give.
