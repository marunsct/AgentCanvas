# Building for the Microsoft Agent Framework

The workflow becomes an async function per block under AgentCanvas's flow engine; AI blocks are Agent Framework
Agents (an OpenAI chat client, tools, a `response_format` for typed answers). Tool calls can wait for a person's
approval (`approval_mode`).

Before proposing the move, call `export_plan` for this framework and tell the person what it lists. Say what the
framework will not do; promise nothing the facts below do not give.
